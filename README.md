## 📋 Описание
Десктопное приложение на WPF (Windows Presentation Foundation) для ведения личного дневника и заметок с синхронизацией через Firebase Realtime Database.
## 🛠 Технологии
- Платформа: .NET Framework / .NET Core (WPF)
- Язык: C#
- База данных: Firebase Realtime Database
- Библиотеки:
  - Firebase.Database
  - Newtonsoft.Json (JSON.NET)-

# 🎯 Основные функции
##📊 Два основных раздела:
- Дневник (Dates Page) - для дневниковых записей, обычно с датами
- Заметки (Notes Page) - для произвольных заметок

## ✍️ Функциональность:
- Создание новых записей
- Редактирование существующих записей
- Удаление записей
- Переименование с автоматическим переносом данных
- Обновление списка в реальном времени

## 🔄 Синхронизация
- Автоматическая загрузка данных из Firebase
- Мгновенное сохранение изменений
- Возможность ручного обновления
